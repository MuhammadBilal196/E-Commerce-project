# TechStore - E-Commerce Web Application

A responsive, 5-page e-commerce storefront. This project demonstrates front-end layout fundamentals, responsive design, and client-side state management.

## Project Features

*   **5 Distinct Views:** Includes Home, About, Contact, Cart, and a dynamically rendering Product Details page.
*   **Dynamic Data Rendering:** Uses JavaScript and URL parameters (`?item=...`) to populate a single `product.html`.
*   **Client-Side State Management:** Implements browser `localStorage` to save shopping cart items. The cart persists even when the user navigates between pages or refreshes the browser.
*   **Responsive UI:** Built with modern CSS Grid and Flexbox to ensure seamless rendering across mobile, tablet, and desktop viewports.
*   **Modern Design:** Features CSS transitions, hover states, and a `@keyframes` fade-in animation for a polished user experience.

## Technologies Used

*   HTML5 (Semantic markup)
*   CSS3 (Variables, Flexbox, Grid, Animations)
*   JavaScript (ES6, DOM Manipulation, Local Storage API)

## How to Run the Project

1. Clone this repository or download the project folder to your local machine.
2. No build tools or package managers are required.
3. Simply open `index.html` directly in any modern web browser (Google Chrome, Firefox, Microsoft Edge).
4. (Optional) For the best experience, open the folder in a code editor like VS Code and use the **Live Server** extension to launch the app.
