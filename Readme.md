# Simple E-Commerce Application

A 3-page e-commerce storefront built for a Web Development Internship task.

## Features
*   **3 Distinct Pages:** Home/Storefront, Product Details, and Shopping Cart.
*   **Animations & Transitions:** Includes CSS hover states on product cards and buttons, and a `@keyframes` fade-in animation on page load.
*   **Client-Side State Management:** Uses JavaScript `localStorage` to save cart items so data persists as the user navigates between pages.
*   **Responsive:** Grid and Flexbox layouts adapt smoothly to mobile screens.

## Technologies
*   HTML5
*   CSS3
*   JavaScript
